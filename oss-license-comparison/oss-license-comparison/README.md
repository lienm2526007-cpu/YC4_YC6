# oss-license-comparison

Phân tích và so sánh ba giấy phép phần mềm nguồn mở (GPLv3, MIT, Apache 2.0)
thông qua ba dự án CNTT tiêu biểu: GNU Bash, React và TensorFlow.

## Giới thiệu đề tài
Giấy phép quyết định ai được dùng, sửa, phân phối và thương mại hóa phần mềm.
Đề tài tìm hiểu sự khác biệt đó và tác động tới cộng đồng phát triển.

## Mục tiêu
- Phân tích mục tiêu, cộng đồng, giấy phép của 3 dự án nguồn mở.
- So sánh giấy phép về quyền sử dụng, tác động cộng đồng, khả năng thương mại hóa.
- Đưa ra nhận xét giấy phép nào phù hợp với loại dự án nào.

## Phương pháp
1. Chọn 3 dự án, mỗi dự án một giấy phép khác nhau.
2. Đọc văn bản giấy phép gốc và tài liệu của dự án (README, trang chủ, kho mã).
3. Lập bảng so sánh theo các tiêu chí thống nhất.

## Kết quả
Xem báo cáo tại `docs/report/main.tex` (biên dịch trên Overleaf) và bảng tổng hợp trong `results/`.

## Cấu trúc thư mục
```
data/      dữ liệu thu thập (số liệu dự án, trích dẫn giấy phép)
src/       mã nguồn/script hỗ trợ (nếu có)
docs/      tài liệu, báo cáo LaTeX (docs/report/)
results/   bảng so sánh, hình, kết quả cuối
```
