# Báo cáo YC1 – Overleaf, mẫu Springer LNCS

Báo cáo 5 trang: *Dự đoán kết quả học tập của học sinh bằng cây quyết định và gom nhóm K-Means*. Tác giả: Phạm Lê Trường Thịnh.

- Dữ liệu: UCI Student Performance (P. Cortez, 2008), https://doi.org/10.24432/C5TG7T, giấy phép CC BY 4.0.
- 13 tài liệu tham khảo, mỗi tài liệu có DOI (`references.bib`).
- Biên dịch: Overleaf → New Project → Upload Project (thư mục này, dạng .zip) → compiler **pdfLaTeX**. Lớp `llncs` có sẵn trên Overleaf.
